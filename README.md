# Dominó

Dominó doble seis estilo latino, en parejas o mano a mano contra la computadora. Tiene versión de escritorio (pygame) y de navegador (Phaser 3).

## Escritorio

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

## Navegador

```bash
cd web
python3 -m http.server 8000
```

Abre <http://localhost:8000>.
